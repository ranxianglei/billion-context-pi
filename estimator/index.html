Formulas

Prices (normalized, 1 unit = 1 token at base input price):  p_cw = w,  p_cr = r,  p_out = q
Geometry:            V' = V - S                      post-fold view
                     X  = h · V'                     first divergence point (cached prefix)
                     T  = (1 - h) · V'               re-paid tail after a fold
                     σ  = β · S                      summary output (persisted)

One-time fold cost:  ΔC₁(h,S) = (w - r) · T + q·β·S - r·S          exact increment
                     (upper bound when baseline cache can't be assumed: w · T instead of (w-r)·T)
Per-turn saving:     Δs = (1 - β) · S · r̄ ,   r̄ = r + (g / (Vmin + S/2)) · (w - r)
Break-even turns:    n*(S) = ΔC₁ / Δs                            strictly decreasing in S (fixed h)
Steady-state cost:   C(S) = r̄·(Vmin + S/2) + (g/S) · [(w-r)(1-h)·Vmin + (qβ - r)·S]
Optimal fold size:   S* = sqrt( 2·g·(w-r)·(1-h)·Vmin / r̄ )       interior when q·β > r
Cadence guardrail:   k ≥ n*(S)                                    else each cycle loses money
TTL extension:       r_eff = r + P_idle·(w - r)                   inter-turn gap > provider TTL (~5 min)
Dollar conversion:   $ = K-units × ($in/M) / 1000
